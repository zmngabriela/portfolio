# Personal Portfolio Website

This project is my personal portfolio website, built to showcase selected work, technical skills, and frontend development projects in a clear and polished way.

## Overview

The portfolio was developed with a strong focus on responsiveness, visual presentation, and multilingual support. It includes project highlights, contact information, and a customizable interface with light and dark themes.

## Tech Stack

- React
- TypeScript
- Styled Components
- React-i18next
- Vite
- Vercel

## Features

- Responsive layout for desktop and mobile
- Light and dark theme toggle
- Multilingual support (English, Portuguese, and Spanish)
- Project showcase with links to live demos and repositories
- Skills and tools section
- Contact section

## Purpose

This project was created to present my work in a more structured way and to reflect both my technical skills and visual sensibility as a developer.
